## [🦄文章&教程](https://weekly.pythoncat.top)

1、[Django 20 周年快乐！](https://simonwillison.net/2025/Jul/13/django-birthday/)

Django 的起源可追溯到 2003 年堪萨斯州劳伦斯市的一家小报社，两位开发者因对 PHP 的局限性感到不满，决定用 Python 开发新的 Web 框架。Django 之父回忆了 Django 从无到有的创造过程，展现了技术选择背后的思考，对理解开源项目的发展很有启发意义。

2、[用 Python 探索 Llama Stack：工具调用和智能体](https://developers.redhat.com/articles/2025/07/15/exploring-llama-stack-python-tool-calling-and-agents)

介绍了如何用 Python 与 Llama Stack 进行工具调用和智能体开发。从环境搭建开始，展示了工具定义、函数实现和 API 调用的完整流程，特别强调了使用文档端点进行 API 探索的技巧，是一篇实用的 LLM 开发指南。

3、[从 SQL 到 SQLModel：Python 操作数据库的更简洁方式](https://pybit.es/articles/from-sql-to-sqlmodel-a-cleaner-way-to-work-with-databases-in-python/)

SQLModel 由 FastAPI 作者开源，用 Python 对象和类型注解替代 SQL 查询来操作数据库。基于 Pydantic 和 SQLAlchemy 开发，提供数据验证、IDE 支持和更好的可测试性，显著提升代码的清洁度和可维护性。

4、[有时候，继承胜过组合](https://death.andgravity.com/over-composition)

作者深入对比了三种实现混合并发执行器的方案：继承方案代码最简洁且向前兼容性最好，组合方案需要大量样板代码，纯函数方案虽然简单但存在全局状态问题，挑战了"组合优于继承"的传统观念。

5、[2025 年的 Python 和 Make](https://onebadbit.com/posts/2025/07/python-and-make-in-2025/)

分享了使用 GNU Make 管理 Python 项目的现代化工作流。通过简化 Makefile 并结合 uv 工具，实现跨平台的项目自动化管理，包括虚拟环境创建、依赖安装和复杂构建流程。

6、[用 Asyncio Protocols 开发简单 HTTP 服务器](https://jacobpadilla.com/articles/asyncio-protocols)

文章介绍了如何用 Asyncio Protocols 这一底层回调机制开发 HTTP 服务器，相比高级的 Streams 抽象，Protocols 避免了协程开销，能更快响应网络事件，性能测试显示比 FastAPI 快约 8 倍。

7、[面向数据科学家的 DuckDB 深度解析](https://codecut.ai/deep-dive-into-duckdb-data-scientists/)

文章介绍了 DuckDB 这个嵌入式 SQL 数据库的核心特性，通过对比 pandas 展示了其在内存效率和性能上的优势，演示了如何零配置使用 DuckDB、与 pandas/Polars 无缝集成，以及自动解析各种文件格式的能力。

8、[我正在转向 Python 并且真的喜欢它](https://www.cesarsotovalero.net/blog/i-am-switching-to-python-and-actually-liking-it.html)

作者因 AI 开发需求而转向 Python，分享了从脚本工具到生产级应用的完整工具链。通过 uv、ruff、FastAPI 等工具构建单仓库架构，配合 Docker 和 GitHub Actions 实现自动化部署，展现了 Python 生态系统的成熟和开发效率。

9、[2048：迭代器和可迭代对象](https://nedbatchelder.com/blog/202507/2048_iterators_and_iterables.html)

作者在开发 2048 游戏时遇到迭代器陷阱，解释了 range() 返回可重用的可迭代对象，而 reversed() 返回一次性迭代器的区别。使用 itertools.product() 巧妙解决了嵌套循环中的迭代器复用问题，深入浅出地分享了 Python 迭代机制的核心概念。

10、[如何严重搞错 Django 外键？](https://hakibenita.com/django-foreign-keys)

文章剖析了 Django 外键的常见陷阱和优化技巧，从替换 unique_together 到识别重复索引，再到安全迁移外键约束，详细讲解了如何避免阻塞迁移、实现并发索引操作等生产环境中的关键问题。

11、[Python 日志记录：可观测性实用指南](https://www.dash0.com/guides/logging-in-python)

这篇教程介绍了从 logging 模块的四大组件到 JSON 格式输出，再到 YAML 配置和异步处理，全面覆盖了日志系统的开发实践，是一份实用的生产环境日志系统开发指南。

12、[前员工分享 OpenAI 工作体验](https://calv.info/openai-reflections)

前 OpenAI 员工分享了真实的工作体验。从自下而上的研究文化到全 Slack 沟通模式，从 7 周开发 Codex 的疯狂节奏到 Python 巨型单体仓库架构，揭示了这家 AI 巨头内部的运作机制和工程实践。

13、[关于在开源软件中使用大模型的思考](http://droettboom.com/blog/2025/07/13/how-to-think-about-llms-for-oss-development/)

作者基于 25 年开源开发经验，提出了在开源软件中应用 LLM 的理性思考框架。强调开源协作本质上是复杂的社会动态系统，建议仅在学习和创作中谨慎使用 LLM，但在开源协作时保持人类主导。

## [🐿️项目&资源](https://weekly.pythoncat.top)

1、[Kimi-K2：先进的智能代理大模型](https://github.com/MoonshotAI/Kimi-K2)

Moonshot AI 开源模型，拥有 32B 激活参数和 1T 总参数，支持 128K 上下文长度。采用 Muon 优化器训练，在前沿知识、推理和编程任务上表现出色。（star 5.4K）

2、[BrowserOS：开源智能代理浏览器](https://github.com/browseros-ai/BrowserOS)

开源的智能代理浏览器，基于 Chromium，专注于隐私保护和本地 AI 处理。它支持在本地使用自己的 API 密钥或通过 Ollama 运行本地模型，可以执行网页表单填写、数据提取等重复性任务，未来还将支持 MCP 商店和内置 AI 广告拦截器。（star 2.6K）

![](https://img.pythoncat.top/2025-07-19-browser-os.png)

3、[macOS-use：让 AI 代理控制 Mac 应用](https://github.com/browser-use/macOS-use)

让 AI 代理能够与 MacBook 交互的工具，能够执行从简单的计算器操作到复杂的网页登录等任务。项目的愿景是让 AI 智能体在任何 Apple 设备上执行任何操作，未来计划支持本地推理和 iPhone/iPad 设备。（star 1.5K）

4、[SuperClaude：Claude Code 增强框架](https://github.com/NomenAK/SuperClaude)

一个增强 Claude Code 的配置框架，提供 16 个专业化命令、智能角色系统和 MCP 服务器集成。支持开发、分析、质量控制等各类编程任务，通过智能路由选择合适的工具和专家，让开发工作流程更加顺畅。（star 9.1K）

5、[pymanager：Python 安装管理器](https://github.com/python/pymanager)

Python 官方推出的 Windows 平台 Python 安装管理器，基于 PEP 773 提案。支持多版本 Python 管理、自动化安装配置，提供 MSIX 和 MSI 两种安装包格式，简化 Windows 的环境管理体验。

6、[mcp-for-beginners：微软推出的 MCP 入门教程](https://github.com/microsoft/mcp-for-beginners)

微软开源的教程，包含 .NET、Java、TypeScript、JS 和 Python 等语言示例。从基础概念到高级主题，包含服务器构建、客户端开发、安全实践、多模态集成等完整学习路径。（star 5.2K）

7、[acp：新的 AI 智能体通信协议](https://github.com/i-am-bee/acp)

开放的 AI 智能体通信协议，支持多模态消息传递，包括文本、代码、文件和媒体内容，提供实时、后台和流式响应。具备智能体发现、长期任务协作和状态共享功能，配套完整的 Python 和 TypeScript SDK。

![](https://img.pythoncat.top/2025-07-19-deeplearning-ai-acp.png)

8、[RapidOCR：多平台多语言 OCR 工具包](https://github.com/RapidAI/RapidOCR)

基于 ONNXRuntime、OpenVINO、PaddlePaddle 和 PyTorch 的多平台多语言 OCR 工具包。支持中英文识别，可快速离线部署，提供 Python、C++、Java、C# 等多种语言接口。（star 4.6K）

9、[Voxtral：开源语音理解模型](https://mistral.ai/news/voxtral/)

Mistral AI 发布的开源语音理解模型，提供 24B 和 3B 两个版本。支持长达 30 分钟的语音转录、内置问答和摘要、多语言支持、语音直接调用函数等功能，在转录准确性和语义理解方面超越 Whisper 等现有模型。

10、[html-to-markdown：现代化 HTML 转 Markdown 工具](https://github.com/Goldziher/html-to-markdown)

基于 markdownify 重写的 Python 库，支持完整的 HTML5 元素转换。支持严格的类型安全、元数据提取、流式处理、高亮文本支持、任务列表转换等功能，代码覆盖率达到 100%。

11、[aiosqlitepool：高性能异步 SQLite 连接池](https://github.com/slaily/aiosqlitepool)

为异步 SQLite 应用设计的高性能连接池，通过复用长连接消除连接开销，保持 SQLite 内存页缓存热度，显著提升并发查询性能。支持连接健康检查、自动事务回滚和空闲连接替换，在高负载下可提升 72% 的查询吞吐量。

12、[epub-translator：AI 驱动的 EPUB 电子书翻译工具](https://github.com/oomol-lab/epub-translator)

用大模型翻译 EPUB 电子书，保留原书格式、插图、目录和布局，同时生成双语对照版本。支持多语言翻译、自定义提示词、多种 AI 模型选择和高性能并行处理。

13、[ai-engineering-hub：LLM 和 AI 智能体深度教程](https://github.com/patchy631/ai-engineering-hub)

关于 LLM、RAG 和 AI 智能体的教程资源，包含从基础概念到实际应用的完整学习路径，涵盖多智能体系统、语音处理、文档分析、知识蒸馏等前沿技术，有丰富的实践案例和代码示例。（star 14.3K）
