## [🦄文章&教程](https://weekly.pythoncat.top)

1、[CPython JIT 的原理解密](https://savannah.dev/posts/how-your-code-runs-in-a-jit-build/)

深入剖析 CPython 的 JIT 编译机制，从 token 解析到字节码再到机器码的完整链路，特别揭示了 3.14 中实验性 JIT 如何通过 micro-op 和 copy-and-patch 技术将热点代码转为原生指令，有助于理解 Python 性能优化的技术路线图。

2、[我为何会对 Litestar 感兴趣？](https://www.b-list.org/weblog/2025/aug/06/litestar/)

Litestar 是新兴的异步 Python Web 框架，作者发现它的独立路由装饰器可解决循环导入问题，内置 Pydantic、dataclasses、msgspec 等多验证方案，深度集成 SQLAlchemy 配合 Advanced Alchemy 自动生成数据仓库，可为大项目提供优雅扩展架构。

3、[你或许不需要用到 Python 类](https://adamgrant.micro.blog/2025/07/24/123050.html)

作者指出 Python 内置类型和标准库已能优雅解决大多数场景：用 namedtuple 或 dataclass 替代简单数据容器，用函数取代无状态工具类，用模块自然分组常量，字典列表即可管理状态，善用标准库避免过度设计，让代码保持简洁 Pythonic。

4、[Rust、Python、TypeScript：新的三剑客](https://smallcultfollowing.com/babysteps/blog/2025/07/31/rs-py-ts-trifecta/)

作者预言 AI 编程时代将重塑编程语言的选型：Rust 担纲系统级性能，Python 提供数学与 ML 生态，TypeScript 主宰 Web 与工具链，三者在类型安全与依赖管理上优势互补，构成面向未来的全栈技术组合。

5、[Python 的性能神话与真相](https://lwn.net/SubscriberLink/1031707/73cb0cf917307a93/)

PyPy 核心开发者在 EuroPython 演讲直击性能误区："Python 够快"仅是部分场景，重写热点代码终将撞墙，静态类型对运行时优化毫无帮助，真正的瓶颈在于内存管理和语言语义，作者正开发 SPy 项目探索超高性能 Python 新路径。

6、[Django 原子计数器的三种实现](https://blog.ovalerio.net/archives/2924)

文章介绍了三种避免竞态条件的 Django 计数方案：数据库锁的 `select_for_update`、原子操作的 `F()` 表达式、缓存层的 `cache.incr`，可按精度需求灵活选择。

7、[别直接调用 Python 双下方法了](https://www.pythonmorsels.com/avoid-dunder-methods/)

作者认为应当定义双下方法让 Python 解释器调用，而非直接调用它们；使用 str()、len()、in 等高级接口而非 obj.\_\_str\_\_()、obj.\_\_len\_\_()，不涉及底层细节并确保行为一致性。

8、[在 OpenGist 中渲染 Jupyter Notebook](https://blog.fabiomanganiello.com/article/render-your-jupyter-notebooks-in-opengist)

OpenGist 前端原生支持 .ipynb 文件渲染，无需后端改动即可像 GitHub 一样展示 notebook；支持代码高亮、Markdown、LaTeX，让你自建私有 gist 服务也能优雅分享 Jupyter 工作流。

9、[如何解决 Python 版本管理混乱？](https://www.mostlypython.com/updating-python/)

作者分享了从 pyenv 迁移到 uv 的使用经验：先用 pyenv 卸载旧版本，再用 brew 移除冗余安装，最后统一用 uv 管理本地 Python，让版本切换更简单、系统更清爽。

10、[Conda 生态系统详解](https://conda.org/blog/2024-08-14-conda-ecosystem-explained)

文章系统梳理了 conda 生态三大支柱：跨语言 CLI 工具、频道化包仓库（conda-forge、bioconda 等）与构建体系，并点出 Mamba、Pixi 等新工具对核心格式的兼容，理清了 conda 庞大生态的脉络。

11、[setuptools 与 setup\.py 的前世今生](https://www.bitecode.dev/p/whats-the-deal-with-setuptools-setuppy)

文章梳理了 setuptools 的演进脉络：从早期 distutils 的 setup\.py 到 setuptools 的声明式配置，再到 pyproject\.toml 的现代标准；指出 setup\.py 虽仍可用但已非必需，新项目应拥抱 pyproject\.toml 的简洁统一。

12、[系统设计的朴素智慧](https://www.seangoedecke.com/good-system-design)

作者提炼了系统设计核心：好的设计应该简单朴素，状态管理是最大挑战，数据库设计最关键，应最小化有状态组件，用简单可演进的架构替代过度复杂的分布式方案。

## [🐿️项目&资源](https://weekly.pythoncat.top)

1、[zotero-arxiv-daily：基于 Zotero 文献库的 arXiv 论文智能推荐](https://github.com/TideDra/zotero-arxiv-daily)

arXiv 论文智能推荐工具，通过分析你已有的文献，利用 AI 生成摘要并通过邮件每日推送。通过 GitHub Actions 部署，无需安装，配置简单。（star 3.1K）

2、[Office-PowerPoint-MCP-Server：PowerPoint 文稿操作的 MCP 服务器](https://github.com/GongRzhe/Office-PowerPoint-MCP-Server)

使用 python-pptx 库，提供 32 个专业工具，涵盖幻灯片管理、文本格式化、图表创建等 11 个模块。支持模板、多样的颜色方案、渐变背景、图片特效等高级功能，可由 AI 智能体直接操作。

3、[pipecat：实时语音和多模态对话 AI 智能体框架](https://github.com/pipecat-ai/pipecat)

用于开发实时语音和多模态对话 AI 智能体。轻松编排音频、视频、AI 服务和对话管道，支持语音助手、AI 伴侣等多种应用场景，具备超低延迟的实时交互能力。（star 7.5K）

4、[sniffly：Claude Code 分析面板](https://github.com/chiphuyen/sniffly)

一个 Claude Code 日志分析工具，帮助开发者更好使用 Claude Code。提供使用模式分析、错误分解和消息历史分析等功能，并能将分析结果以可分享的仪表板形式展示。

5、[FastVideo：统一的视频生成加速框架](https://github.com/hao-ai-lab/FastVideo)

一个视频生成加速框架，涵盖了从数据预处理到模型训练、微调、蒸馏和推理的全流程。支持多种硬件和操作系统，并集成了稀疏蒸馏、视频稀疏注意力等多种性能优化技术，旨在实现高效、可扩展的视频生成。（star 1.8K）

6、[judgeval：AI 智能体后训练层工具](https://github.com/JudgmentLabs/judgeval)

通过追踪和评估智能体与环境的交互，为强化学习、监督式微调、监控和回归测试提供数据和信号，从而实现智能体的持续学习和自我改进。

7、[viser：基于 Web 的 3D 可视化库](https://github.com/nerfstudio-project/viser)

用于计算机视觉和机器人学的基于 Web 的 3D 可视化 Python 库。提供了 3D 原始数据可视化、GUI 构建、场景交互和相机控制等功能，易于上手且能组合成复杂界面，方便通过 SSH 在服务器上运行。（star 1.7K）

8、[stock: 股票分析利器](https://github.com/myhhub/stock)

功能全面的股票分析工具，支持数据获取、指标计算、形态识别、策略选股、回测和自动交易。该项目兼容 PC 和移动设备，并提供 Docker 镜像，方便量化投资者使用。（star 9.8K）

9、[langmem: AI 智能体长期记忆管理](https://github.com/langchain-ai/langmem)

帮助 AI 智能体学习和适应长期交互的工具。能从对话中提取关键信息，通过 prompt 优化智能体行为，并维护长期记忆，与 LangGraph 原生集成，实现持续改进和个性化响应。

10、[Auto-Gmail-Creator: 批量 Gmail 账户自动创建](https://github.com/ai-to-ai/Auto-Gmail-Creator)

使用 Selenium 和 Seleniumwire 实现的批量 Gmail 账户自动创建机器人。该工具能自动化完成 Gmail 注册，并集成了短信服务用于手机验证，支持多浏览器和代理配置。

11、[nvda: 免费开源的屏幕阅读器](https://github.com/nvaccess/nvda)

适用于 Microsoft Windows 的免费、开源屏幕阅读器。它由 NV Access 主导开发，旨在让视障人士能够无障碍地使用电脑。（star 2.4K）

12、[sshsync：远程服务器命令同步工具](https://github.com/Blackmamoth/sshsync)

在多个远程服务器上通过 SSH 并发执行 shell 命令的 CLI 工具。它支持对服务器进行分组管理，可以方便地对指定分组的服务器执行命令，并支持文件推送和拉取。
