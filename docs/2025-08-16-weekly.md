## [🦄文章&教程](https://weekly.pythoncat.top)

1、[pyx：Python 原生软件包仓库](https://astral.sh/blog/introducing-pyx)

Astral 推出 pyx，一个 Python 原生软件包仓库。不仅是传统软件包仓库，更是 uv 的优化后端，通过垂直整合客户端和服务器解决了 PyTorch 安装困难、团队重复开发包、版本兼容性等痛点问题。支持 GPU 感知、私有包托管和公共源加速。

2、[pytest parametrize 入门指南](https://nedbatchelder.com/blog/202508/starting_with_pytests_parametrize.html)

讲解了 pytest 的 parametrize 装饰器用法，通过实例演示了如何消除代码重复。从基础的多个测试函数开始，逐步展示如何使用 @pytest.mark.parametrize 将测试数据参数化，既减少了代码冗余又提高了测试的可维护性。

3、[HRT 的 Python 分支：利用 PEP 690 实现更快导入](https://www.hudsonrivertrading.com/hrtbeat/inside-hrts-python-fork)

HRT 博客分享了他们基于 Cinder 实现的懒加载导入机制，通过延迟模块解析和求值直到实际引用时才执行，显著减少了启动时间。该方案使用 LazyImport 占位符对象替代立即执行的导入语句，解决了大型代码库中导入开销过大的问题。

4、[Python Wheel：从标签到变体](https://labs.quansight.org/blog/python-wheels-from-tags-to-variants)

介绍了 Python Wheel 变体机制，通过插件架构替代传统平台标签来处理复杂的包分发需求。使用命名空间属性和 JSON 元数据描述包变体，解决了 GPU 加速、CPU 架构和数值库选择等问题，让 PyTorch 等复杂包能更灵活地分发不同版本。

![](https://img.pythoncat.top/2025-08-15-variant-flow-dynamic.png)

5、[7 个加速 Python 数据科学工作流的方案](https://developer.nvidia.com/blog/7-drop-in-replacements-to-instantly-speed-up-your-python-data-science-workflows)

NVIDIA 博客介绍了 7 种 GPU 加速方案，通过简单的参数设置或扩展加载即可提升 pandas、Polars、scikit-learn、XGBoost 等库的性能，无需修改现有代码就能获得显著的速度提升。

6、[DeepSeek-R1 能否优化世界上最古老的代码库之一？](https://tonybaloney.github.io/blog/can-reasoning-models-optimize-20-year-old-code.html)

作者用 DeepSeek-R1 优化 CPython 内核中有 20 年历史的大数运算代码，在 70B 到 371B 参数的多轮实验中，AI 既展现了惊人的优化洞察，也闹出了让 Python 直接崩溃的乌龙。

7、[Python 半自动化汇编验证](https://www.philipzucker.com/assembly_verify/)

作者开发了基于 pypcode 的汇编验证工具，通过在汇编代码中添加内联注释来定义前置条件、断言和后置条件，实现对二进制代码的半自动化验证。

8、[Python 版本依赖路径问题](https://utcc.utoronto.ca/~cks/space/blog/python/PythonVersionPathProblem)

文章分析了 Python 包安装路径与版本绑定的设计问题，指出这种机制虽然解决了字节码和 C ABI 兼容性问题，但导致版本升级时所有包都需重新安装。

9、[Python 如何从语言发展为社区？](https://thenewstack.io/how-python-grew-from-a-language-to-a-community/)

回顾了 Python 从 1991 年诞生到成为全球最受欢迎编程语言的社区发展历程，从 1994 年马里兰州 20 人聚会开始形成真正的社区，经历了早期商业化尝试失败、基金会组织架构探索等关键节点，强调了社区价值观和人的力量在 Python 成功中的重要作用。

10、[PEP-802：空集显示语法](https://peps.python.org/pep-0802/)

这则新发布的 PEP 提出一种空集语法 `{/}`，通过模仿数学符号 ∅ 来解决当前空集只能用 `set()` 构造的问题。这个语法避免了名称查找，提升了初学者的学习体验，特别是对数学背景用户更友好。已在社区投票中获得 41% 支持率，计划在 Python 3.15 中实现。

11、[mssql-python vs pyodbc：SQL Server 性能基准测试](https://devblogs.microsoft.com/python/mssql-python-vs-pyodbc-benchmarking-sql-server-performance/)

微软推出 SQL Server Python 驱动 mssql-python，通过 DDBC 直连架构和 PyBind11 绑定技术，在核心 SQL 操作中比 pyodbc 快 2-4 倍，批量插入快 8.6 倍，1000 连接创建快 16.5 倍。

12、[使用 plotnine 创建注释面积图](https://nrennie.rbind.io/blog/plotnine-annotated-area-chart)

教程展示了如何用 plotnine 创建专业的注释面积图，通过煤炭生产数据可视化演示了从数据预处理到图表美化的完整流程。文章涵盖自定义网格线、多层注释、颜色配置和字体管理等高级技巧。

## [🐿️项目&资源](https://weekly.pythoncat.top)

1、[marker：高精度快速 PDF 转换工具](https://github.com/datalab-to/marker)

高精度文档转换工具，支持 PDF、图片、PPTX、DOCX、XLSX、HTML、EPUB 等格式转换为 markdown、JSON、HTML。能够格式化表格、公式、内联数学、链接和代码块，提取保存图像，移除页眉页脚。（star 27.6K）

2、[stagehand-python：AI 浏览器自动化框架](https://github.com/browserbase/stagehand-python)

结合自然语言和代码的浏览器自动化框架，支持 act（执行操作）、extract（数据提取）、observe（页面观察）、agent（多步任务）四大功能。可预览和缓存操作，集成 OpenAI 和 Anthropic 的计算机使用模型。

面向树莓派和 PC 的开源数字标牌平台。支持多种树莓派型号，兼容 balenaOS 和 Raspberry Pi OS。提供完整的数字标牌解决方案，适用于商业展示、信息发布等场景。（star 3.1K）

4、[YTSage：现代化 YouTube 下载器](https://github.com/oop7/YTSage)

基于 PySide6 的现代化 YouTube 下载器，支持任意质量视频下载、音频提取、字幕获取、SponsorBlock 去广告、播放列表下载等功能。提供简洁的图形界面，支持格式表格、多字幕选择合并、缩略图保存、视频剪切等高级功能。（star 1.8K）

5、[free-llm-api-resources：免费 LLM API 资源列表](https://github.com/cheahjs/free-llm-api-resources)

精心整理的 LLM API 资源清单，涵盖 OpenRouter、Google AI Studio、NVIDIA NIM、Mistral、Groq、Cerebras 等多个平台。详细列出各服务的使用限制、支持模型和访问方式。（star 4.7K）

6、[Biomni：通用生物医学 AI 智能体](https://github.com/snap-stanford/Biomni)

斯坦福开发的通用生物医学 AI 智能体，结合大模型推理、检索增强规划和代码执行能力。支持 CRISPR 筛选设计、单细胞 RNA 测序注释、ADMET 性质预测等多种生物医学研究任务，提供 Web 界面和 MCP 协议支持。（star 2K）

7、[genai-processors：模块化 AI 管道开发库](https://github.com/google-gemini/genai-processors)

Google Gemini 开发的轻量级 Python 库，用于构建模块化、异步和可组合的生成式 AI 管道。基于 Processor 概念设计，支持流式处理、并行执行、链式组合等功能，支持文本、图像、音频等多模态数据。（star 1.9K）

8、[SQLBot: 基于大模型和 RAG 的智能问数系统](https://github.com/dataease/SQLBot)

智能问数系统，支持自然语言转 SQL 查询。开箱即用，只需配置大模型和数据源即可使用。易于集成到第三方系统，支持 n8n、MaxKB、Dify、Coze 等平台调用，提供工作空间资源隔离和细粒度权限控制。

9、[notte：可靠的浏览器 AI 智能体](https://github.com/nottelabs/notte)

结合 AI 智能体与传统脚本，支持结构化输出、隐身浏览器会话、混合工作流、凭证管理和数字身份等功能，可降低 50% 以上成本并提高可靠性。（star 1.5K）

10、[Dolphin：异构锚点提示的文档图像解析](https://github.com/bytedance/Dolphin)

字节开源的多模态文档图像解析模型，采用分析-解析两阶段方法，支持文本、表格、公式等多种文档元素的高效处理，提供 Hugging Face 和原生框架两种推理方式。（star 5.5K）

11、[open-notebook：Notebook LM 开源替代](https://github.com/lfnovo/open-notebook)

隐私优先的 Google Notebook LM 替代方案，具备多模态内容组织、专业播客生成、智能搜索、上下文对话等功能。提供完整数据主权、成本控制、无限定制和 API 访问，支持 Docker 部署和本地运行。（star 3.4K）

12、[botasaurus：强大的爬虫开发框架](https://github.com/omkarcloud/botasaurus)

全能网页爬虫开发框架，可破解各种机器人检测系统如 Cloudflare、BrowserScan、Fingerprint 等。支持人性化鼠标移动、桌面应用转换、网站界面开发、代理成本节省高达 97%。提供简单的并行化、配置文件、扩展和代理配置，集成缓存、站点地图、数据清理等实用工具。（star 2.8K）
