## [🦄文章&教程](https://weekly.pythoncat.top)

1、[Python 2025 年现状报告](https://blog.jetbrains.com/pycharm/2025/08/the-state-of-python-2025)

 Python 软件基金会和 JetBrains 联合发布的第八届开发者调查报告出炉了！揭示了重要趋势：86% 的受访者将 Python 作为主要编程语言，50% 的开发者编程经验不足两年，数据科学已占据 Python 应用的半壁江山。

2、[Python 文件流传输：8 美元服务器上实现 237MB/s](https://bellone.com/updates/axon-api/python-file-streaming-237mbs-on-$8-m-droplet-in-507-lines-stdlib)

作者开发了一个 WSGI 核心 Axon，仅用 507 行纯 Python 标准库代码就在 8 美元月费的服务器上实现了 237MB/s 的文件流传输性能。该框架把 HTTP 请求体映射成可迭代字节流，边收边发，内存占用恒定在几十 KB。

3、[有时 LFU 比 LRU 更好](https://www.revsys.com/tidbits/sometimes-lfu-lru/)

面对恶意 AI 爬虫大量创建一次性会话导致真实用户会话被挤出缓存的问题，作者提出用 LFU（最少使用频率）替代传统 LRU（最近最少使用）缓存策略。通过配置 Redis 的 volatile-lfu 模式，能有效保护频繁访问的用户会话，确保电商购物车等关键业务数据不被恶意流量冲刷。

4、[上下文工程：DSPy 全面实战教程](https://towardsdatascience.com/context-engineering-a-comprehensive-hands-on-tutorial-with-dspy/)

文章深入介绍了上下文工程，通过 DSPy 框架演示如何将复杂问题分解为多个子任务，让不同能力的 AI 智能体协作完成，避免了将所有信息塞入单一上下文导致的性能下降问题。

5、[Python 代理对象的实现原理](https://crowdalert.com/proxy-objects/)

深入解析 Python 代理对象的实现原理，通过特殊方法实现对象调用的透明代理。展示如何利用这一机制开发数据库连接池、文件系统抽象等高级功能。

6、[PyPI 防范域名复活攻击](https://blog.pypi.org/posts/2025-08-18-preventing-domain-resurrections/)

PyPI 推出新的安全机制来防范域名复活攻击。当用户邮箱域名过期后，攻击者可能购买该域名并通过密码重置获取账户控制权。PyPI 会定期检查域名状态，一旦发现域名进入赎回期就会取消相关邮箱验证，有效阻断这类供应链攻击。

7、[以符号模式匹配的视角设计算法](https://symbolica.io/posts/pattern_matching/)

文章分享了如何用符号模式匹配来设计算法，通过 Symbolica 库将图论问题转化为数学表达式操作。作者演示了用模式替换实现阶乘计算、图连通性检测等算法，虽然效率不是最优但提供了一种优雅的算法思维方式。

8、[Python 约束编程：用 CP-SAT 解决优化问题](https://pganalyze.com/blog/a-practical-introduction-to-constraint-programming-using-cp-sat)

文章通过声明式编程范式介绍约束编程，用变量和约束描述问题。以 Python CP-SAT 求解器演示如何解决仓库选址、物流调度等离散优化问题，展现了约束编程在处理复杂组合优化场景中的强大能力。

9、[Python BDFL 称号的起源](https://www.artima.com/weblogs/viewpost.jsp?thread=235725)

Guido van Rossum 的博客旧文，揭秘了 BDFL（终身仁慈独裁者）称号的起源。1995 年 4 月 18 日在 CNRI 的 Python 软件协会首次会议上，每个与会者都起了以"First Interim"开头的头衔，而 Guido 的头衔最为幽默。这个称号很可能由 Ken Manheimer 或 Barry Warsaw 提出，成为 Python 社区文化的重要标志。

10、[ASCII 雨滴滚动艺术](https://mathspp.com/blog/ascii-rain-scroll-art)

文章展示了如何用纯 Python 标准库创建终端雨滴动画效果。通过 deque 数据结构管理，用字符 v 和 | 分别表示雨滴和尾迹，结合随机数生成和时间延迟实现流畅的下雨动画。代码简洁优雅，仅需几十行就创造出令人印象深刻的视觉效果。

11、[人性化的超时和取消机制](https://vorpus.org/blog/timeouts-and-cancellation-for-humans/)

Trio 库作者深入探讨 I/O 操作中超时处理的设计难题，分享 Trio 的 cancel scopes 解决方案。通过取消令牌和作用域机制，解决传统超时 API 难以抽象和组合的问题，为异步编程提供更人性化的超时控制方式。

12、[你只需要两个日志级别：INFO 和 ERROR](https://ntietz.com/blog/the-only-two-log-levels-you-need-are-info-and-error)

作者挑战传统日志分级思维，认为复杂的日志级别体系（如 WARNING、DEBUG、TRACE）实际上并不实用。通过分析日志的两个核心用途——"需要警报的错误"和"帮助调试的信息"，提出只用 ERROR 和 INFO 两个级别就足够了，同时建议通过结构化日志、请求 ID、时间戳等方式提升日志的实用性。

## [🐿️项目&资源](https://weekly.pythoncat.top)

1、[parlant：可控的 LLM AI 智能体](https://github.com/emcie-co/parlant)

一个 AI 智能体框架，通过自然语言而非复杂的系统提示词来定义行为准则，确保智能体严格遵循指令。支持对话流程管理、工具集成、领域适配和模板响应等功能，可在 60 秒内快速部署。（star 7.3K）

2、[GhostTrack：位置和手机号追踪工具](https://github.com/HunxByts/GhostTrack)

用于追踪位置或手机号码的 OSINT 信息收集工具。支持 IP 地址追踪、手机号码信息查询和社交媒体用户名搜索功能，可在 Linux 和 Termux 环境下运行。（star 2.8K）

![](https://img.pythoncat.top/2025-08-22-ghost-track.png)

3、[Archon：AI 编程助手的知识管理平台](https://github.com/coleam00/Archon)

为 AI 编程助手提供知识库和任务管理的命令中心。支持文档爬取、PDF 上传、智能搜索和任务管理，通过 MCP 协议连接 Claude Code、Cursor 等 AI 工具，提升 AI 驱动编程的效果。（star 10.2K）

4、[mcp-context-forge：MCP 网关和注册中心](https://github.com/IBM/mcp-context-forge)

一个 MCP 网关和注册中心，作为工具、资源和提示词的中央管理。支持将 REST API 端点转换为 MCP，组合虚拟 MCP 服务器并增加安全性和可观测性。（star 1.4K）

5、[tensorlake：文档摄取 API 和无服务器数据处理平台](https://github.com/tensorlakeai/tensorlake)

一个将非结构化文档转换为 AI 可用数据的平台，通过 API 解析 PDF、DOCX、电子表格等格式，并提供无服务器工作流运行时来开发可扩展的数据处理管道。

6、[flower：Celery 分布式任务队列监控工具](https://github.com/mher/flower)

开源的 Celery 集群监控和管理 Web 应用，提供任务进度查看、工作节点状态监控、远程控制和队列统计等功能。支持实时事件监控、HTTP 认证、Prometheus 集成和 REST API，是 Celery 分布式任务处理的必备管理工具。（star 6.9K）

7、[AI-Researcher：自主科学创新研究系统](https://github.com/HKUDS/AI-Researcher)

提供从概念到发布的端到端研究自动化，包括文献综述、创意生成、算法设计实现、结果分析和论文撰写等功能。支持详细创意描述和基于参考文献的创意生成两种输入模式。（star 2K）

8、[tilf：像素艺术编辑器](https://github.com/danterolle/tilf)

一个免费的像素艺术编辑器，使用 PySide6 开发，支持绘制工具、实时预览、撤销重做和导出功能，专为创建精灵、图标和小2D资产设计。无需注册或安装，即开即用。

9、[plutoprint：HTML 到 PDF 和图像生成库](https://github.com/plutoprint/plutoprint)

轻量易用的 Python 库，可将 HTML 或 XML 内容生成高质量 PDF 和图像。基于 PlutoBook 渲染引擎，提供简单 API，适合创建报告、发票或视觉快照。支持命令行，还可集成 Matplotlib 生成图表。

10、[SpatialLM：3D 点云数据大模型](https://github.com/manycore-research/SpatialLM)

专为处理 3D 点云数据而设计的大模型，能够生成结构化的 3D 场景，包括墙壁、门窗等建筑元素和带语义类别的定向物体边界框。支持多种数据源如单目视频、RGBD 图像和激光雷达传感器，有效连接非结构化 3D 几何数据。（star 3.9K）

11、[One-KVM：DIY IP-KVM 远程控制解决方案](https://github.com/mofeng-git/One-KVM)

利用廉价硬件实现 BIOS 级别的远程服务器管理。支持 Docker 部署、中文界面、视频录制和虚拟存储挂载等功能，无需在目标机器安装软件即可进行远程控制，适用于家庭实验室和服务器维护场景。（star 1.6K）

12、[Notte：可靠的浏览器 AI 智能体框架](https://github.com/nottelabs/notte)

全栈框架，用于构建和部署可靠的浏览器 AI 智能体。结合 AI 智能体与传统脚本，提高效率并降低成本。支持自然语言任务执行、Pydantic 结构化输出、网站交互、隐身浏览器会话、混合工作流、秘密保险库和数字角色等功能。
