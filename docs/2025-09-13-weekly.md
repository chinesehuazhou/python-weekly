## [🦄文章&教程](https://weekly.pythoncat.top)

1、[在自由线程 Python 中扩展 asyncio](https://labs.quansight.org/blog/scaling-asyncio-on-free-threaded-python)

Python 3.14 在无 GIL 构建中优化了 asyncio，通过改进任务管理和线程状态存储，单线程性能提升约 10%–20%，多线程下可真正并行扩展。在基准测试中，aiohttp 吞吐量几乎翻倍，TCP 场景也有显著提升，使网络和 I/O 应用能更好利用多核。

2、[Google 停止支持 Pytype：Python 类型检查时代的终结](https://pydevtools.com/blog/google-sunsets-pytype-the-end-of-an-era-for-python-type-checking/)

Google 宣布停止维护运行了 13 年的 Pytype 类型检查器，止步 Python 3.12。基于字节码分析的架构是其致命弱点，难以跟上 Python 类型系统的快速演进。虽然 Pytype 在跨函数边界的流分析和大型代码库处理方面独树一帜，但其批处理模式无法满足现代开发对增量检查和 LSP 集成的需求。

3、[测试代码依赖的编译器优化](https://pythonspeed.com/articles/testing-compiler-optimizations/)

当编译器将看似 O(n) 的循环优化为常数时间操作时，如何确保这种优化能持续有效？文章通过 Numba 和 LLVM 示例，展示了用 CPU 指令计数替代运行时间测量的方法。这种技术能可靠检测编译器是否真正执行了预期优化，避免性能回退。

4、[自定义 Python REPL 颜色方案](https://treyhunner.com/2025/09/customizing-your-python-repl-color-scheme/)

Python 3.14 新增了 REPL 语法高亮功能，但默认配色可能与你的编辑器不匹配。通过 `_colorize` 模块的 `set_theme` 函数，自定义关键字、字符串、注释等元素的颜色，配合 `PYTHONSTARTUP` 环境变量，能让个性化配色在每次启动时自动生效。

5、[Semlib：LLM 驱动的数据处理](https://anishathalye.com/semlib/)

Semlib 提供了用自然语言描述的函数式编程原语，可用 map、reduce、sort 等操作来开发数据处理管道。它将复杂任务分解为更小的步骤，避免了直接向 LLM 灌入所有数据的低效做法。通过结构化计算和并发处理，不仅提升了结果质量，还能处理任意规模的数据，同时支持成本优化和模型选择。

6、[如何/为何用 Bazel 开发 Python 代码？](https://ohadravid.github.io/posts/2025-09-hello-bazel/)

介绍了谷歌开源的构建工具 Bazel，它通过依赖图管理，能精确追踪外部依赖和内部模块关系，避免不必要的重复开发。支持多语言混合开发，比如无缝集成 Rust 扩展，随着项目复杂度增长价值愈发明显。

7、[PEP-679：支持 assert 语句括号语法](https://peps.python.org/pep-0679/)

PEP 679 提议支持 `assert (expr, msg)` 括号语法，解决初学者误用括号导致断言失效的问题，同时改善多行断言的格式化体验。

8、[PEP-803：为自由线程开发提供稳定 ABI](https://peps.python.org/pep-0803/)

PEP 803 提议将 PyObject 结构体设为不透明类型，可让 Python 3.15 的稳定 ABI 同时兼容自由线程和 GIL 开发模式，需要扩展模块迁移到新 API 以支持无锁并发。

9、[为 R 和 Python 设置本地 LLM](https://posit.co/blog/setting-up-local-llms-for-r-and-python)

介绍了如何使用 Ollama 在本地部署大模型，通过 chatlas（R）和 ellmer（Python）包实现与本地 LLM 的交互，避免数据隐私风险的同时享受 AI 辅助编程体验。

10、[如何让 AI "看懂"网页？拆解 Browser-Use 的三大核心技术模块](https://www.bestblogs.dev/article/bedb12)

Browser-Use 是 AI 驱动的浏览器自动化工具，文章剖析了它的三大技术模块：DOM 树解析（包括 JavaScript 端的递归遍历、Python 端的树构建、可交互元素识别与视觉标注）、记忆模块（MessageManager 的消息管理、截断策略及基于 mem0 的记忆压缩）以及工具注册与管理（内置 Action 合集、装饰器注册机制与工具调用流程）。

11、[为 AI 智能体编写有效工具](https://www.anthropic.com/engineering/writing-tools-for-agents)

Anthropic 分享了如何为 AI 智能体开发高质量工具？通过 MCP 让智能体获得数百种工具能力，采用原型开发、评估测试、协作优化的迭代流程，优化 token 效率、提供有意义的上下文反馈，让智能体能够有效解决现实世界的复杂任务。

12、[Chrome 浏览器 17 年发展史](https://addyosmani.com/blog/chrome-17th/)

Google Chrome 工程师回顾了 Chrome 从 2008 年诞生至今的 17 年发展历程：从最初的多进程架构革新到 V8 引擎的性能突破，Chrome 始终围绕速度、安全、稳定、简洁四大原则演进。通过隔离标签页进程、重构渲染管道、引入 AI 功能等创新，让浏览器从简单网页查看器进化为现代 Web 应用平台。
