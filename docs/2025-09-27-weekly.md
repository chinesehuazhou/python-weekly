## [🦄文章&教程](https://weekly.pythoncat.top)

1、[在现实世界中追踪 JIT](https://antocuni.eu/2025/09/24/tracing-jits-in-the-real-world--cpython-core-dev-sprint/)

PyPy 核心开发者在 CPython 核心开发者冲刺会议上分享了 7 年高频交易公司优化 PyPy 的实战经验。深入对比了 CPython JIT 与 PyPy JIT 的相似性，揭示了追踪 JIT 在真实代码中面临的挑战，包括追踪阻塞器、性能不可预测性等问题。

2、[编译 Python 让其随处运行](https://blog.codingconfessions.com/p/compiling-python-to-run-anywhere)

作者分享了开发 Python 编译器的实践经验，通过符号追踪和 IR 生成将原生 Python 代码编译为跨平台机器码。该方案借鉴 Unity IL2CPP 架构，先生成 C++ 源码再编译为可执行文件，无需解释器即可运行。作者从 AI 模型分发痛点出发，探索了比容器更轻量的分发方式，为 Python 性能优化提供了新思路。

3、[PEP-806：混合 sync/async 上下文管理器](https://peps.python.org/pep-0806/)

该 PEP 提议在单个 with 语句中混合使用同步和异步上下文管理器，意图解决现有代码中"楼梯式厄运"的深度嵌套问题，提升代码可读性。提案基于对工业代码库的调研，发现 19% 的异步函数同时使用了同步上下文管理器，新语法将显著改善开发体验。

4、[介绍 django-watchfiles：高效的 runserver 自动重载](https://adamj.eu/tech/2025/09/22/introducing-django-watchfiles)

作者发布了 django-watchfiles 新版本，用基于 Rust 的 watchfiles 库替代 Django 默认的文件轮询机制。该工具通过操作系统的文件监控 API 实现更高效的自动重载，在中等规模项目测试中 CPU 使用率从 10% 降至 0%。相比需要额外维护的 Watchman 方案，django-watchfiles 安装简单且更加可靠。

5、[使用 Cursor AI 将 Bash 测试套件迁移到 Python](https://developers.redhat.com/articles/2025/09/23/how-i-used-cursor-ai-migrate-bash-test-suite-python)

分享了使用 Cursor AI 将容器测试套件从 Bash 迁移到 Python 的实战经验。通过简单的提示词，Cursor AI 自动分析 Bash 脚本并生成对应的 Python 库，还创建了完整的 PyTest 测试套件，整个迁移过程节省了约 1.5 个月的开发时间。

6、[解锁 Python 自由线程的性能潜力：垃圾收集优化](https://labs.quansight.org/blog/free-threaded-gc-3-14)

详解了 Python 3.14 自由线程版本的垃圾收集器优化技术，对比了传统 GIL 版本与自由线程版本的 GC 实现差异，介绍了"标记存活"阶段、软件预取和智能 GC 触发等三项关键优化。这些改进在 pyperformance 基准测试中实现了显著性能提升，为无 GIL Python 的实用化奠定了重要基础。

7、[边缘计算中的 Python：基于 WebAssembly 的快速沙盒化运行](https://wasmer.io/posts/python-on-the-edge-powered-by-webassembly)

Wasmer 推出基于 WebAssembly 的 Python 边缘计算解决方案，通过 WASIX 技术实现接近原生性能的沙盒化运行。支持 FastAPI、Django、Streamlit 等主流框架，兼容 numpy、pandas 等原生模块，提供多线程和 WebSocket 支持。相比 Cloudflare Workers 和 AWS Lambda，具有更好的兼容性和更快的冷启动速度。

8、[Python 依赖混淆攻击：我如何入侵苹果、微软等公司？](https://medium.com/@alex.birsan/dependency-confusion-4a5d60fec610)

安全研究员揭示了一种新颖的供应链攻击方式，通过在公共包仓库上传与企业内部包同名的恶意包来实现入侵。攻击利用了包管理器优先级混淆，成功渗透了苹果、微软等数十家大公司。文章详细介绍了攻击原理、实施过程和防护建议，为开发者敲响了依赖管理安全的警钟。

9、[在 Django 项目中使用内省强制执行约定](https://lukeplant.me.uk/blog/posts/enforcing-conventions-in-django-projects-with-introspection/)

介绍了如何利用 Python 强大的内省能力来自动化检查 Django 项目中的命名约定，通过结合 Django 的系统检查框架，作者实现了对 DateField 和 DateTimeField 字段命名规范的自动验证，有效避免了字段类型混淆导致的潜在问题。

10、[计算机科学中的优秀思想](https://danielchasehooper.com/posts/good-ideas-in-cs/)

作者梳理了计算机科学中被普遍认可的核心思想，从 16 世纪的二进制数到 1970 年代的公钥密码学，涵盖了数组、哈希表、调用栈、虚拟地址空间等基础概念。

11、[为什么事件驱动系统难以开发？](https://newsletter.scalablethread.com/p/why-event-driven-systems-are-hard)

深入分析了事件驱动系统在大规模应用中面临的核心挑战，通过生动的比喻解释了模式演进、调试复杂性、消息可靠性和幂等性等关键问题，并提供了实用的解决方案，包括模式注册中心、分布式追踪、死信队列等技术。

![](https://img.pythoncat.top/2025-09-26-Event-Driven.png)

12、[软件工程师如何做出高效决策？](https://strategizeyourcareer.com/p/how-software-engineers-make-productive-decisions?hide_intro_popup=true)

作者提出"双向门"决策框架，将技术决策分为可逆和不可逆两类，通过快速风险评估，对可逆决策（如功能开关、内部库替换）采用快速试错策略，对不可逆决策（如数据迁移、架构变更）则谨慎处理。这种方法能避免过度投入可逆决策，同时确保高风险决策的安全性。

## [🐿️项目&资源](https://weekly.pythoncat.top)

1、[timesfm：Google 时间序列基础模型](https://github.com/google-research/timesfm)

Google 开源的预训练时间序列基础模型，专用于时间序列预测。最新版本 TimesFM 2.5 使用 200M 参数，支持最长 16k 上下文长度，能够进行连续分位数预测。（star 5.8K）

2、[aipyapp：AI 驱动的 Python 解释器](https://github.com/knownsec/aipyapp)

知道创宇开发的集成大模型的 Python 命令行解释器，支持自然语言描述需求自动生成并执行 Python 代码，提供任务模式和 Python 模式两种运行方式。可以处理数据清洗、转换、分析等各种数据工程任务，无需手动编写代码或复制粘贴。（star 2.4K）

3、[ticket-purchase：大麦自动抢票脚本](https://github.com/WECENG/ticket-purchase)

基于 Selenium 和 Appium 开发的大麦网自动抢票工具，支持 Web 端和移动端两种方式，可配置观演人员、城市、日期场次、价格等参数，实现无延时自动抢票，支持回流监听和自动提交订单功能。（star 3.5K）

4、[memvid：视频化 AI 记忆库](https://github.com/Olow304/memvid)

创新的 AI 记忆存储方案，将文本数据编码为 QR 码存储在 MP4 视频文件中，实现毫秒级语义搜索。相比传统向量数据库存储空间减少 50-100 倍，无需数据库基础设施，支持离线运行。通过视频编解码器的压缩优势，提供便携、高效的知识库解决方案。（star 9.2K）

5、[noScribe：AI 音频转录工具](https://github.com/kaixxx/noScribe)

基于 OpenAI Whisper 和 pyannote 技术，支持说话人识别和 60 种语言转录，完全本地运行无需联网。内置编辑器可校对修正转录结果，支持暂停标记、重叠语音检测等高级功能。（star 1.4K）

![](https://img.pythoncat.top/2025-09-26-noScribe.png)

6、[klavis：AI 智能体工具集成平台](https://github.com/Klavis-AI/klavis)

让 AI 智能体可靠地使用数千种工具的 MCP 集成平台。提供统一的 MCP 路由器和 50+ 生产级 MCP 服务器，支持 GitHub、Gmail、Slack 等主流服务的企业级 OAuth 认证。支持自托管和云服务两种部署方式，提供 Python、TypeScript SDK 和 REST API。（star 4.4K）

7、[fastapi-radar：FastAPI 调试仪表板](https://github.com/doganarif/fastapi-radar)

专为 FastAPI 应用设计的强大调试仪表板，提供实时的 HTTP 请求、SQL 查询和异常监控。只需一行代码即可集成，零配置开箱即用。支持 SQL 和 NoSQL 数据库，具备请求响应捕获、慢查询检测、异常堆栈跟踪等功能。

8、[air：新一代 Python Web 框架](https://github.com/feldroy/air)

基于 FastAPI、Starlette 和 Pydantic 构建的新一代 Python Web 框架。提供 Air Tags 快速 HTML 编码、Jinja 模板兼容、HTMX 友好集成和 Pydantic 驱动的表单验证。

9、[OM1：模块化机器人 AI 运行时](https://github.com/OpenMind/OM1)

模块化的机器人 AI 运行时系统，支持在数字环境和物理机器人上创建和部署多模态 AI 智能体。可处理网页数据、社交媒体、摄像头和激光雷达等多种输入，实现运动控制、自主导航和自然对话等物理动作。支持人形机器人、四足机器人、手机应用和教育机器人等多种平台。

10、[Ciphey：全自动加密破解工具](https://github.com/bee-san/Ciphey)

全自动的加密解密和编码破解工具，无需知道密钥或加密方式即可自动识别并破解。支持 50 多种加密和编码方式，包括 Base64、摩尔斯电码、凯撒密码、维吉尼亚密码等经典密码，以及现代加密如重复密钥异或等。使用自定义 AI 模块和自然语言处理技术，大多数破解任务可在 3 秒内完成，比 CyberChef 等工具快 7 倍。（star 19.6K）

11、[DBOS Transact：轻量级持久化工作流](https://github.com/dbos-inc/dbos-transact-py)

基于 Postgres 的轻量级持久化工作流系统，通过简单的函数注解即可为 Python 程序添加持久化工作流和队列功能。支持自动故障恢复、持久化队列、事件处理、调度和通知等功能，无需额外的基础设施配置。

12、[CleverBee：AI 驱动的在线数据信息合成助手](https://github.com/SureScaleAI/cleverbee)

基于 Python 的 AI 驱动在线数据信息合成助手，集成多种大模型进行智能研究。使用 Playwright 实现自动化网页浏览，Chainlit 提供交互式用户界面。支持多模型研究、自动网页浏览、内容处理、令牌跟踪和高度可配置性，能够自动收集和分析网络信息。
