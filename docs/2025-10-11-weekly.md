## [🦄文章&教程](https://weekly.pythoncat.top)

1、[Python 3.14.0 正式发布！](https://pythoninsider.blogspot.com/2025/10/python-3140-final-is-here.html)

Python 3.14.0 正式版终于来了！这个版本带来了众多重磅新特性：正式支持自由线程 Python、模板字符串字面量、延迟注解求值、支持多解释器、Zstandard 压缩算法等。还包含实验性 JIT 编译器、改进的错误消息、Android 官方二进制发布等。

2、[Python 3.14 来了，速度如何？](https://blog.miguelgrinberg.com/post/python-3-14-is-here-how-fast-is-it)

作者通过递归计算斐波那契数列和冒泡排序算法测试了 Python 3.14 的性能表现。相比 Python 3.13，新版本在单线程环境下速度提升约 20%，在多线程场景中表现更加出色。虽然与 PyPy、Node.js 和 Rust 相比仍有差距，但 Python 3.14 展现了持续的性能优化趋势，为纯 Python 代码带来了显著的速度提升。

3、[Python 3.14 我最喜欢的 5 个新特性](https://blog.codingconfessions.com/p/python-3-14-whats-new)

作者分享了 Python 3.14 的五大亮点特性：自由线程 Python 实现真正的并行计算、并发解释器模块支持多解释器并行执行、远程调试功能可直接附加到运行中的进程、增量垃圾回收减少延迟峰值、以及性能优化带来的显著提升。

4、[介绍 Air：开创性的 AI 优先 Python Web 框架](https://audrey.feldroy.com/articles/2025-10-06-air-pioneering-ai-first-python-web-framework)

作者正在开发的新 Web 框架 Air，融合了 Django、FastHTML、Flask 等框架的优秀特性，支持 Python 对象生成 HTML 和 Jinja 模板两种方式，内置 HTMX 支持，展现出为 AI 代码生成优化的巨大潜力。

5、[PEP 810：显式惰性导入](https://peps.python.org/pep-0810/)

这个 PEP 提议为 Python 3.15 引入显式惰性导入语法，使用 `lazy import json` 语句延迟模块加载。模块只在首次使用时才真正加载和执行，而不是在导入语句处立即加载，能显著减少启动时间和内存使用。

6、[将 NumPy 的类型完整性提升至近 90%](https://pyrefly.org/blog/numpy-type-completeness)

Quansight Labs 和 Meta Pyrefly 团队合作将 NumPy 的类型完整性从 33% 大幅提升至近 90%。通过修复一个类型注解错误就将覆盖率翻倍至 80%，随后完整类型化 MaskedArray 类推至 90%，显著改善了 IDE 的代码提示和静态类型检查体验。

7、[用 Django 和 SQLite 实现全文搜索](https://www.screamingatmyscreen.com/full-text-search-with-django-and-sqlite/)

作者展示了如何在 Django 博客中使用 SQLite 的 FTS5 扩展实现全文搜索功能，避免了引入 ElasticSearch 这样的重型解决方案。通过创建虚拟表和数据库触发器来同步内容，使用原生 SQL 查询实现搜索排序。

8、[为什么花了 4 年才制定出锁定文件规范？](https://snarky.ca/why-it-took-4-years-to-get-a-lock-files-specification/)

作者回顾了 Python 锁定文件规范 PEP-751 的艰难历程，从 2019 年开始经历了多次提案失败和重新设计。锁定文件需要记录依赖关系图、支持多平台兼容、处理 NP 完全问题的依赖解析等复杂挑战。最终通过与 uv、Poetry、PDM 等工具的协作达成共识，形成了 pylock.toml 规范，为 Python 生态系统带来了标准化的依赖管理解决方案。

9、[PEP 8 不只有命名风格](https://inventwithpython.com/blog/sweigarts-law-of-pep-8-complaints.html)

作者提出了一个有趣的观察：每当有人抱怨代码违反 PEP 8 时，总是在说不遵守蛇形命名，却从不提 PEP 8 的其它内容。文章探讨了代码风格指南的真正意义，指出 PEP 8 强调的是一致性而非盲目遵循，项目内部的一致性比严格遵循指南更重要。

10、[为什么响应式编程在 Python 中没有流行起来？](https://bui.app/why-reactive-programming-hasnt-taken-off-in-python-and-how-signals-can-change-that)

作者分析了响应式编程在 Python 中普及困难的原因，指出 RxPY 虽然功能强大但过于复杂，不适合简单的状态管理。文章介绍了 reaktiv 库如何通过信号机制实现透明的响应式编程，让状态同步变得像电子表格公式一样简单直观。

11、[介绍 tdom：使用 Python t-strings 的 HTML 模板](https://davepeck.org/2025/09/22/introducing-tdom-html-templating-with-python-t-strings/)

介绍了 tdom 库，它利用 Python 3.14 的新 t-strings 特性实现现代化的 HTML 模板功能。库支持动态属性、特殊属性处理、直观的内容嵌套和类似 JSX 的组件语法，同时自动转义特殊字符确保安全性，让 Python Web 模板开发变得更加直观和强大。

12、[Python 公案1：空的路径](https://pythonkoans.substack.com/p/koan-1-the-empty-path)

《Python Koans》系列文章第一篇，深入探讨了 Python 中的真值概念，解释了如何通过定义 `__bool__` 和 `__len__` 方法来控制对象在布尔上下文中的行为，展示了 Python 中"真"不是简单的 True/False 二元概念，而是对象表达自身意义的方式。（分享自@julio-mcdulio）

3、[devpush：开源的 Vercel 替代方案](https://github.com/hunvreus/devpush)

开源且可自托管的部署平台，支持 Python、Node.js、PHP 等多种语言。提供基于 Git 的零停机部署、实时日志监控、团队协作管理、自定义域名和 SSL 证书等功能。采用 Docker 容器化技术，支持多环境管理和分支映射。（star 2K）

4、[pyscn：智能 Python 代码质量分析器](https://github.com/ludo-technologies/pyscn)

5、[FuncToWeb：Python 函数转成 Web 界面](https://github.com/offerrall/FuncToWeb)

可将任何 Python 函数转换为 Web 界面，只需添加类型提示并调用 run() 函数即可生成完整的 Web 表单。支持所有 Python 内置类型、文件上传、下拉菜单、可选参数等功能，提供实时上传进度条和错误处理。

6、[Logly：Rust 驱动的高性能 Python 日志库](https://github.com/muhammad-fiaz/logly)

Rust 开发的高性能 Python 日志库，提供类似 Loguru 的 API 体验。采用 Rust 后端确保内存安全和线程安全，支持多种日志级别、结构化 JSON 输出、智能文件轮转、多目标输出、异步回调等功能。零配置即可使用，提供丰富的过滤选项和自定义格式化。

7、[ApeRAG：生产级图 RAG 平台](https://github.com/apecloud/ApeRAG)

结合图 RAG、向量搜索和全文搜索技术，支持多模态文档处理、AI 智能体、MCP 协议集成，提供五种索引类型（向量、全文、图、摘要、视觉）。集成 MinerU 文档解析服务，支持 Kubernetes 部署和企业级管理功能，包括审计日志、模型管理、图可视化等。

8、[autoswagger：API 认证检测工具](https://github.com/intruder-io/autoswagger)

通过解析 Swagger/OpenAPI 文档自动检测未认证的 API，支持多阶段发现机制、并行端点测试、参数值暴力破解，集成 Presidio 进行 PII 检测和正则表达式敏感信息识别。能够检测 API 中的个人信息泄露、密钥暴露等安全问题。（star 1.5K）

9、[computer-use-preview：计算机使用预览模型](https://github.com/google/computer-use-preview)

Google 的计算机使用预览模型，通过自然语言控制浏览器执行各种操作。支持 Playwright 本地浏览器控制和 Browserbase 云端环境，集成 Gemini API 和 Vertex AI。通过简单的命令让 AI 智能体自动完成网页搜索、表单填写、页面导航等复杂任务，提供鼠标位置高亮和可视化调试功能。（star 1K）

10、[varia：支持文件、种子和视频的下载管理器](https://github.com/giantpinkrobots/varia)

跨平台下载管理器，支持 Linux 和 Windows 系统，能够处理常规文件、BitTorrent 种子和视频音频流下载。作为 aria2 和 yt-dlp 的图形化前端，提供 Flatpak、Snap、AUR 等多种安装方式，还包含浏览器扩展支持。具备自动更新、关机后完成下载、多语言支持等实用功能。

![](https://img.pythoncat.top/2025-10-11-Varia.png)

11、[holm：类 Next.js 的 Python Web 开发框架](https://github.com/volfpeter/holm)

基于 FastAPI、htmy 和 FastHX 开发的 Web 框架，为 Python 带来类似 Next.js 的开发体验。支持文件系统路由、JSX 语法组件、服务端渲染、HTMX 集成等功能。无需 JavaScript 依赖和构建步骤，提供完全类型化的 Python 开发环境。支持异步组件、JSON 和 HTML API、自动页面布局等特性。

12、[snakeviz：浏览器中的 Python 性能分析可视化工具](https://github.com/jiffyclub/snakeviz)

基于浏览器的 Python 性能分析数据可视化工具，用于查看 cProfile 模块的输出结果，是标准库 pstats 模块的图形化替代方案。提供冰柱图和旭日图两种可视化风格，支持 IPython 魔法命令和 Jupyter Notebook 集成，能够直观显示函数调用关系和时间消耗。（star 2.5K）
