## [🦄文章&教程](https://weekly.pythoncat.top)

1、[PSF 撤回 150 万美元政府资助申请](https://pyfound.blogspot.com/2025/10/NSF-funding-statement.html)

Python 软件基金会主动撤回了美国国家科学基金会 150 万美元的资助申请，因为资助条款要求 PSF 承诺不开展任何推进多样性、公平性和包容性的项目，但 PSF 董事会一致决定坚持价值观，拒绝背叛其支持多元化 Python 社区的使命。

2、[CPython 核心开发者 2025 冲刺活动创历史新高](https://pyfound.blogspot.com/2025/10/cpython-core-dev-sprint-2025-at-arm.html)

Arm 剑桥总部举办了史上最大规模的 CPython 核心开发者冲刺活动，48 位开发者齐聚一堂进行深度技术交流，活动涵盖 JIT 编译器、性能优化、包管理、语言设计等核心议题，推进了自由线程、文档改进等重要进展。

3、[Python 的 OrderedDict 为什么有序？](https://www.piglei.com/articles/why-is-python-ordereddict-ordered/)

为什么 OrderedDict 能记住插入顺序而普通字典不行？作者深入 OrderedDict 类型的内部实现，揭秘其有序性的根本原因：在字典基础上增加双向链表维护顺序信息，配合索引字典实现快速定位。另外分享了有趣的细节，如通过 weakref 巧妙解决"环形引用"，以及用 object() 作为默认值的设计。

4、[探索和改进 NumPy 测试套件的线程安全性](https://labs.quansight.org/blog/numpy-thread-safe-test-suite)

作者深入分析 NumPy 测试套件在并行执行时的线程安全问题，通过引入 pytest-run-parallel 插件识别并修复了全局状态污染、随机数种子冲突等关键缺陷，将测试执行速度提升了数倍。

5、[可靠的 Django 信号](https://hakibenita.com/django-reliable-signals)

Django 信号看似简单却暗藏陷阱——当信号处理失败时会导致整个事务回滚。作者揭示了信号机制的根本缺陷，并提出用 Celery 等后台任务队列替代同步信号的实用方案，有效避免因信号异常影响主业务流程。

6、[uv 是十年来 Python 生态系统最好的工具](https://emily.space/posts/251023-uv)

uv 用 Rust 重写了整套工具链，从版本安装到依赖解析都快得惊人，作者详细对比了 uv 与传统工具的性能差异，展示了它如何将复杂的环境配置变成一条命令的事。

7、[理解 Docker 内部原理：用 Python 构建容器运行时](https://muhammadraza.me/2024/building-container-runtime-python/)

作者用不到 200 行 Python 代码重现了容器的核心机制，从 Linux 命名空间到 cgroups 资源限制，每个步骤都有详细代码示例。

8、[PEP 686：默认启用 UTF-8 模式](https://peps.python.org/pep-0686/)

正在开发中的 Python 3.15 已实现 PEP-686，将默认启用 UTF-8 模式，统一文件、标准输入输出和管道的编码为 UTF-8，解决跨平台编码不一致问题，提升与其它语言的互操作性。

9、[我第一个创业公司的糟糕技术架构](https://blog.jacobstechtavern.com/p/my-terrible-startup-architecture)

创业公司的技术债是怎么积累的？作者毫不掩饰地复盘了自己的"黑历史"——从 Django + React 的简单架构，到为了"可扩展性"而过度设计的微服务地狱。什么时候该坚持简单，什么时候才需要复杂？

10、[Python 3.14 那些没上头条的新特性](https://www.bitecode.dev/p/python-314-what-didnt-make-the-headlines)

作者分享了 Python 3.14 中不被人重视的实用改进：PDB 调试器支持远程调试和更好的断点策略，asyncio 简化事件循环管理，argparse 增强帮助信息和错误提示，多进程在 Linux 上改用更安全的 forkserver 策略。

11、[Helion：高性能机器学习内核 DSL](https://pytorch.org/blog/helion)

PyTorch 推出的高级领域特定语言，将类似 PyTorch 的语法编译为优化的 Triton 代码，通过自动调优引擎和隐式搜索空间，让开发者专注算法逻辑而非硬件细节，实现跨硬件架构的性能可移植性。

12、[缓存：计算机中最优雅的创新](https://planetscale.com/blog/caching)

一篇精美的交互式缓存教程，通过可视化动画展示缓存原理，从 CPU 多级缓存到数据库缓存策略，用动态图表演示命中率变化、时间局部性、空间局部性等核心概念，让抽象的缓存机制变得直观易懂。

2、[quark-auto-save：夸克网盘自动转存](https://github.com/Cp0204/quark-auto-save)

夸克网盘签到、自动转存、命名整理、发推送提醒和刷新媒体库一条龙工具，支持分享链接子目录、智能文件过滤、正则文件名整理、多任务管理、Emby 媒体库集成等功能。提供 Docker 部署和 WebUI 配置界面，支持多账号管理和插件扩展，可与 SmartStrm、Emby 配合实现自动追更效果。（star 2.1K）

3、[AI-Trader：AI 智能体股票交易](https://github.com/HKUDS/AI-Trader)

五个 AI 智能体在纳斯达克 100 股票市场中完全自主交易的实验平台，支持多模型竞技场、零人工干预决策、实时性能分析、历史回放功能等。基于 MCP 工具链架构，集成 Jina 搜索获取市场情报，提供完整的交易记录和收益分析，探索 AI 在金融市场中的自主决策能力。（star 7.9K）

![](https://img.pythoncat.top/2025-10-31-AI-Trader.png)

4、[httptap：HTTP 请求分析工具](https://github.com/ozeranskii/httptap)

功能强大的 CLI 工具，将 HTTP 请求分解为 DNS、TCP 连接、TLS 握手、服务器等待和传输等各个阶段，并以瀑布图、紧凑摘要或指标输出形式呈现结果。支持 IPv4/IPv6 识别、TLS 证书分析、多种输出模式、JSON 导出、代理支持等功能。基于 Python 开发，无系统依赖，适用于交互式故障排除、回归分析和性能基准记录。

5、[kanchi：Celery 任务监控系统](https://github.com/getkanchi/kanchi)

一个实时 Celery 任务监控和管理系统，提供友好的用户界面。支持 WebSocket 实时监控、任务过滤搜索、重试跟踪、孤儿检测、每日统计、工作节点健康监控等功能。提供 Docker Compose 快速部署，支持基础认证和 OAuth 登录，兼容 RabbitMQ 和 Redis 消息代理，可替代 Flower 作为更现代的 Celery 监控解决方案。

![](https://img.pythoncat.top/2025-10-31-kanchi.png)

6、[IsaacSim：AI 机器人仿真平台](https://github.com/isaac-sim/IsaacSim)

NVIDIA 开源的 AI 驱动机器人仿真平台，基于 Omniverse 构建。支持 GPU 加速物理仿真、RTX 传感器渲染、多种机器人格式导入、强化学习训练、ROS 集成、合成数据生成等功能。提供 Isaac Lab 框架用于机器人学习，支持数字孪生仿真，为机器人开发的各个阶段提供完整基础设施。（star 1.8K）

7、[scikit-opt：群体智能优化算法库](https://github.com/guofei9987/scikit-opt)

Python 群体智能算法库，集成遗传算法、粒子群优化、模拟退火、蚁群算法、免疫算法、人工鱼群算法、差分进化等多种启发式优化算法。支持用户自定义函数、GPU 计算、多种加速策略（向量化、多线程、多进程、缓存）、约束优化、TSP 问题求解等功能。提供丰富示例和可视化工具，适用于各种复杂优化问题。（star 6.2K）

8、[BettaFish: 多 Agent 舆情分析助手](https://github.com/666ghj/BettaFish) 

一个从零开发的多 AI 智能体舆情分析系统，通过对话式交互分析国内外 30+ 主流社媒平台的数百万条评论。具备 AI 驱动监控、复合分析引擎、多模态能力、智能体论坛协作机制、公私域数据融合等六大优势，帮助用户打破信息茧房，预测舆情走向。(star 2.1K)

9、[moon-dev-ai-agents：自主交易 AI 智能体](https://github.com/moondevonyt/moon-dev-ai-agents)

一个专为算法交易设计的自主 AI 智能体集合，包含回测研究、实时交易、市场分析、内容创作等多种智能体。支持多模型共识决策、并行回测、风险管理、鲸鱼监控、情绪分析、资金费率套利等功能。集成 HyperLiquid、Solana 等多个交易平台，提供完整的从策略研究到实盘交易的自动化解决方案。（star 1.9K）

10、[wove：优雅的 Python 异步编程](https://github.com/curvedinf/wove)

改进 Python 异步编程体验的库，提供比 asyncio 更直观的用户体验，支持自上而下的代码声明、隐式并行执行、同步异步混合、自动任务调度、依赖图构建、零样板代码等功能。基于纯 Python 标准库开发，无外部依赖，兼容自由线程模式，可轻松集成到任何 Python 项目中实现高效的并发处理。

11、[agent-framework：微软 AI 智能体框架](https://github.com/microsoft/agent-framework)

微软开源的多语言 AI 智能体开发框架，支持 Python 和 .NET 双语言实现。提供从简单聊天智能体到复杂多智能体工作流的完整解决方案，具备图形化工作流编排、流式处理、检查点、人机交互、时间旅行等高级功能。集成 DevUI 交互式开发界面、OpenTelemetry 可观测性。（star 4.5K）

12、[ViMax：智能体视频生成平台](https://github.com/HKUDS/ViMax)

集导演、编剧、制片人和视频生成器于一体的多智能体视频创作框架，支持从创意到成片的端到端自动化流程，包括剧本创作、故事板设计、角色创建、场景一致性保持等功能。提供创意转视频、小说改编、剧本生成、个人定制等多种创作模式，解决传统视频制作中的角色一致性、场景连贯性和制作效率等核心问题。
