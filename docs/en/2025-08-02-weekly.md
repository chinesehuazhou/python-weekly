# Python Trending Weekly #113: Replacing Async/Await with Virtual Threads

## [🦄Articles & Tutorials](https://weekly.pythoncat.top)

1. [Checking Out CPython 3.14's Remote Debugging Protocol](https://rtpg.co/2025/06/28/checking-out-sys-remote-exec/)

   Python 3.14's new `sys.remote_exec()` function lets you inject code into a running process without a restart or source code changes. You can perform remote debugging with the `python -m pdb -p pid` command to check status, get stack traces, and even start an interactive session at runtime. This standardized injection mechanism significantly lowers the bar for developing debugging tools.

2. [Operating Inside the Interpreted: Offensive Python](https://trustedsec.com/blog/operating-inside-the-interpreted-offensive-python)

   This article reveals Python's potential as an offensive security tool in a Windows environment. It shows how to easily deploy Python via the Microsoft Store or offline and use the `ctypes` library to call Win32 APIs directly for low-level system operations.

3. [From Async/Await to Virtual Threads](https://lucumr.pocoo.org/2025/7/26/virtual-threads)

   Armin Ronacher explores the future of concurrent programming in Python, proposing virtual threads as a replacement for `async/await`! He envisions a world with structured concurrency and a cleaner API that eliminates the 'function color' problem, handing the complexity of concurrency back to the interpreter. This would allow developers to write concurrent code in a simpler, more intuitive way.

4. [Following up on the Python JIT](https://lwn.net/Articles/1029307)

   How is the CPython JIT compiler being developed? This article breaks down the process, explaining how techniques like tracing and a 'copy-and-patch' mechanism are used to compile only the most frequently executed code paths. It also covers how the JIT handles tricky issues like memory management, debugging, and performance analysis.

5. [asyncio: A Library with Too Many Sharp Corners](https://sailor.li/asyncio)

   Ever been burned by `asyncio`? The author sharply points out its three major design flaws: a messy cancellation mechanism, weakly-referenced tasks, and callback-style I/O, which can easily lead to deadlocks or tasks that mysteriously disappear. Looking for a more elegant concurrency solution? The author recommends Trio/AnyIO.

6. [Building Autonomous Systems: A Guide to Agentic AI Workflows](https://www.digitalocean.com/community/conceptual-articles/build-autonomous-systems-agentic-ai)

   How can we get AI agents to work autonomously like humans? This article demystifies their core workflow: through autonomous planning, tool use, reflection, and multi-agent collaboration, they can achieve capabilities beyond traditional automation. The piece also explores how frameworks like LangChain and AutoGen bring AI to life and how to design reliable feedback mechanisms.

   ![Agentic Workflow](https://img.pythoncat.top/2025-08-02-agentic-workflow.png)

7. [The Big LLM Architecture Comparison](https://open.substack.com/pub/sebastianraschka/p/the-big-llm-architecture-comparison)

   This article systematically compares the architectures of various large models like DeepSeek-V3 and Llama 4. It dives deep into the evolution from multi-head attention to grouped-query attention and multi-head latent attention, and explains how Mixture-of-Experts models achieve efficient inference through sparse activation.

8. [A Better Alternative to Shell Scripts with Python, uv, and pytest](https://hamatti.org/posts/better-alternative-to-shell-scripts-with-python-uv-and-pytest/)

   Learn how to use `uv` and PEP 723's inline metadata feature to develop self-contained Python scripts. Not only can you automatically manage dependencies in a temporary virtual environment, but you can also integrate `pytest` for testing, making your automation scripts more reliable and easier to maintain.

9. [Incident Report: Phishing Attack](https://blog.pypi.org/posts/2025-07-31-incident-report-phishing-attack/)

   PyPI was hit by a phishing attack. Attackers used the lookalike domain `pypj.org` to create a fake website, tricking users into leaking their credentials. This led to malicious code being injected into packages like `num2words`. The incident is a stark reminder of the importance of enabling two-factor authentication (2FA) and using hardware security keys.

10. [Can You Execute Arbitrary Python Code from Only a Comment?](https://www.hacktron.ai/blog/posts/python-zip-confusion)

    Execute arbitrary Python code with just a single comment? This article reveals a clever attack technique that constructs a 'polyglot' file—one that's both a valid Python script and a ZIP archive—to successfully exploit an interpreter feature and achieve code injection!

11. [How the Application and Request Contexts Work in Python Flask](https://blog.appsignal.com/2025/07/23/how-the-application-and-request-contexts-work-in-flask.html)

    Ever wonder why Flask's global objects like `request` work flawlessly in a multi-threaded environment? This article demystifies Flask's core context mechanism, explaining how the application and request contexts work together to ensure data isolation.

12. [Is AI Leaving the Python Community Behind?](https://georgiker.com/blog/is-ai-leaving-python-community-behind/)

    AI's boom owes a lot to Python, but are AI companies starting to cannibalize the community? The article points out that many companies are reaping the benefits of the Python community while giving little back. As 'AI crash course' topics dominate tech conferences and entry-level jobs dwindle due to AI, we have to ask: in our rush to embrace AI, are we undermining the very foundations of the Python community?
