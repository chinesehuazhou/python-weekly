## [🦄Articles & Tutorials](https://weekly.pythoncat.top)

1、[How to Spot (and Fix) 5 Common Performance Bottlenecks in pandas Workflows](https://developer.nvidia.com/blog/how-to-spot-and-fix-5-common-performance-bottlenecks-in-pandas-workflows)

NVIDIA's blog shares a hands-on guide for pandas performance optimization, targeting five major bottlenecks: slow CSV reading, memory-intensive join operations, sluggish string processing, time-consuming group aggregations, and inefficient loop iterations. The guide provides solutions including PyArrow engines, indexed joins, categorical data types, and GPU acceleration. It particularly highlights the cudf.pandas extension, which can deliver order-of-magnitude performance improvements without changing your existing code.

2、[How to use functools\.Placeholder](https://mathspp.com/blog/how-to-use-functools-placeholder)

Python 3.14's new functools.Placeholder solves the positional argument placeholder problem in partial function applications. When you need to freeze non-first parameters of a function, traditional functools.partial can only achieve this through keyword arguments. Placeholder allows you to reserve argument positions with placeholders, enabling more flexible function composition.

3、[Python Namespace Packages are a pain](https://joshcannon.me/2025/08/16/py-namespace-packages.html)

A deep dive into the complexity and real-world issues of Python namespace packages. Namespace packages allow splitting a single import package across multiple disk directories, which is useful in large enterprise projects but introduces challenges with path discovery and module loading. The article explains the differences between explicit and implicit namespace packages, potential issues with different environment managers, and recommends using `__init__.py` in every directory to avoid these complexities.

4、[Enforcing conventions in Django projects with introspection](https://lukeplant.me.uk/blog/posts/enforcing-conventions-in-django-projects-with-introspection/)

Automatically enforce Django model field naming conventions using Python's introspection capabilities to solve DateField and DateTimeField confusion. Using Django's check framework, it requires timestamp fields to end with `_at` and date fields to end with `_on` or `_date`, preventing maintenance headaches and type confusion errors caused by inconsistent naming.

5、[Boosting SEO with Django Ninja, Pydantic, and JSON-LD](https://www.revsys.com/tidbits/boosting-seo-with-django-ninja-pydantic-and-json-ld/)

Generate structured data using Django Ninja and Pydantic as an alternative to directly embedding JSON-LD in templates. This approach provides better code maintainability, type validation, and modular reusability.

6、[AST-Driven Python Testing](https://jazzberry.ai/blog/ast-driven-python-testing)

A hybrid testing approach combining abstract syntax tree analysis with AI generation. By parsing AST to identify code branches, it guides AI to generate precise test cases, achieving systematic high-coverage testing.

7、[Out-Fibbing CPython with the Plush Interpreter](https://pointersgonewild.com/2025-08-06-out-fibbing-cpython-with-the-plush-interpreter/)

The author optimized their custom Plush interpreter to outperform CPython in Fibonacci recursion tests. Through techniques like instruction merging, eliminating hash lookups, and in-place stack operations, they achieved nearly double the performance.

8、[Wicked Python trickery - dynamically patch a Python function's source code at runtime](https://ericmjl.github.io/blog/2025/8/23/wicked-python-trickery-dynamically-patch-a-python-functions-source-code-at-runtime)

A technique for dynamically replacing function source code at runtime using compile and exec functions. While this approach opens new possibilities for building flexible AI agents, it also introduces security risks.

9、[uv format: Code Formatting Comes to uv (experimentally!)](https://pydevtools.com/blog/uv-format-code-formatting-comes-to-uv-experimentally/)

uv 0.8.13 introduces the experimental uv format command, which implements code formatting functionality by calling the Ruff formatter, streamlining Python development workflows.

10、[Expressions are coming to pandas!](https://labs.quansight.org/blog/pandas_expressions)

pandas 3.0 will introduce `pd.col` expression syntax, replacing lambda functions to solve scope issues and providing a cleaner, more readable way for lazy computation with support for method chaining.

11、[What makes concurrency so hard?](https://buttondown.email/hillelwayne/archive/what-makes-concurrency-so-hard/)

Why is concurrent programming so difficult? The author argues that the core issue is state space explosion, not human cognitive limitations. When multiple threads execute simultaneously, the possible execution order combinations grow exponentially, leading to unpredictable and hard-to-debug race conditions. The article suggests that managing and limiting state space is the key strategy for simplifying concurrent programming.

12、[From GPT-2 to gpt-oss: Analyzing the Architectural Advances](https://magazine.sebastianraschka.com/p/from-gpt-2-to-gpt-oss-analyzing-the)

Analyzes the architectural evolution of OpenAI's first open-source large model gpt-oss, including key technologies like MXFP4 optimization, RoPE positional encoding, Swish activation functions, GLU gated units, MoE mixture of experts, GQA grouped query attention, and sliding window attention. These architectural improvements significantly enhance model performance and efficiency.
