# Python 潮流周刊#125：个人 AI 笔记本工具



## [🦄Articles & Tutorials](https://weekly.pythoncat.top)

1、[The PSF has withdrawn a $1.5 million proposal to US government grant program](https://pyfound.blogspot.com/2025/10/NSF-funding-statement.html)

Python 软件基金会主动撤回了美国国家科学基金会 150 万美元的资助申请，因为资助条款要求 PSF 承诺不开展任何推进多样性、公平性和包容性的项目，但 PSF 董事会一致决定坚持价值观，拒绝背叛其支持多元化 Python 社区的使命。

2、[CPython Core Dev Sprint 2025 at Arm Cambridge: The biggest one yet](https://pyfound.blogspot.com/2025/10/cpython-core-dev-sprint-2025-at-arm.html)

Arm 剑桥总部举办了史上最大规模的 CPython 核心开发者冲刺活动，48 位开发者齐聚一堂进行深度技术交流，活动涵盖 JIT 编译器、性能优化、包管理、语言设计等核心议题，推进了自由线程、文档改进等重要进展。

3、[Why is Python's OrderedDict ordered?](https://www.piglei.com/articles/why-is-python-ordereddict-ordered/)

为什么 OrderedDict 能记住插入顺序而普通字典不行？作者深入 OrderedDict 类型的内部实现，揭秘其有序性的根本原因：在字典基础上增加双向链表维护顺序信息，配合索引字典实现快速定位。另外分享了有趣的细节，如通过 weakref 巧妙解决"环形引用"，以及用 object() 作为默认值的设计。

4、[Exploring & Improving the Thread Safety of NumPy's Test Suite](https://labs.quansight.org/blog/numpy-thread-safe-test-suite)

作者深入分析 NumPy 测试套件在并行执行时的线程安全问题，通过引入 pytest-run-parallel 插件识别并修复了全局状态污染、随机数种子冲突等关键缺陷，将测试执行速度提升了数倍。

5、[Reliable Django Signals](https://hakibenita.com/django-reliable-signals)

Django 信号看似简单却暗藏陷阱——当信号处理失败时会导致整个事务回滚。作者揭示了信号机制的根本缺陷，并提出用 Celery 等后台任务队列替代同步信号的实用方案，有效避免因信号异常影响主业务流程。

6、[uv is the best thing to happen to the Python ecosystem in a decade](https://emily.space/posts/251023-uv)

uv 用 Rust 重写了整套工具链，从版本安装到依赖解析都快得惊人，作者详细对比了 uv 与传统工具的性能差异，展示了它如何将复杂的环境配置变成一条命令的事。

7、[Understanding Docker Internals: Building a Container Runtime in Python](https://muhammadraza.me/2024/building-container-runtime-python/)

作者用不到 200 行 Python 代码重现了容器的核心机制，从 Linux 命名空间到 cgroups 资源限制，每个步骤都有详细代码示例。

8、[PEP 686 – Make UTF-8 mode default](https://peps.python.org/pep-0686/)

正在开发中的 Python 3.15 已实现 PEP-686，将默认启用 UTF-8 模式，统一文件、标准输入输出和管道的编码为 UTF-8，解决跨平台编码不一致问题，提升与其它语言的互操作性。

9、[The Terrible Technical Architecture of my First Startup](https://blog.jacobstechtavern.com/p/my-terrible-startup-architecture)

创业公司的技术债是怎么积累的？作者毫不掩饰地复盘了自己的"黑历史"——从 Django + React 的简单架构，到为了"可扩展性"而过度设计的微服务地狱。什么时候该坚持简单，什么时候才需要复杂？

10、[Python 3.14 - What didn't make the headlines](https://www.bitecode.dev/p/python-314-what-didnt-make-the-headlines)

作者分享了 Python 3.14 中不被人重视的实用改进：PDB 调试器支持远程调试和更好的断点策略，asyncio 简化事件循环管理，argparse 增强帮助信息和错误提示，多进程在 Linux 上改用更安全的 forkserver 策略。

11、[Helion: A High-Level DSL for Performant and Portable ML Kernels](https://pytorch.org/blog/helion)

PyTorch 推出的高级领域特定语言，将类似 PyTorch 的语法编译为优化的 Triton 代码，通过自动调优引擎和隐式搜索空间，让开发者专注算法逻辑而非硬件细节，实现跨硬件架构的性能可移植性。

12、[Caching: The Most Elegant Innovation in Computing](https://planetscale.com/blog/caching)

一篇精美的交互式缓存教程，通过可视化动画展示缓存原理，从 CPU 多级缓存到数据库缓存策略，用动态图表演示命中率变化、时间局部性、空间局部性等核心概念，让抽象的缓存机制变得直观易懂。
